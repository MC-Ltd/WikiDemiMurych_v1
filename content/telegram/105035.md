На скрине, ты передаешь ТРИ РАЗНЫХ primitive value, которые согласно устоявшемуся стереотипу должны создать ТРИ РАЗНЫХ записи в коллекции SET.

Вместо этого ты видишь что у тебя ОДИН элемент в SET. Что противоречит общепринятому утверждению о том, что SET коллекция содрежит уникальные значения. Потому, что для JS -0 +0 и 0 - это ТРИ РАЗНЫХ Primitive Value СОГЛАСНО IEE754.

и увидеть это можно например при простом выражении
-0 + 0; // -0
