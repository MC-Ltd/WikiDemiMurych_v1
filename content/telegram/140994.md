Чтобы ответить на этот вопрос нужно четко понимать, что такое тип Object по спецификации.

Введение особого поведения, например для проперти length приводит к тому, что Array становится Exotic Object. То есть обьект с особым поведением.

То есть, введение в спецификацию проперти _proto_ дефакто, с ее точки зрения делает ВСЕ обьекты Exotic Object

Оригинальный тип Object содержит 13 абстрактных операций регулирующих его поведение, где нет никаких  ключей которы связаны с особыми проперти.
