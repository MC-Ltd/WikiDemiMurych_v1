В том, что когда ты знаешь что взаимодействуешь с Object - ты точно знаешь что происходит при любом обращении к нему. 
Это четко стандартизировано спецификацией.

Как только Object - становится Exotic - это означает что его поведение в одном из 13 операций изменено. И теперь ты понятия не имеешь в какой части он себя ведет иначе.
Нужно читать спецификацию по конкретному Exotic Object чтобы описать его поведение. 
И это не обязательно спецификация ECMA

Типичные примеры Exotic Object в JS это:
Array
String
Typed Array
