null - это литерал. То есть Выражение на уровне языка JavaScript которое имеет алгоритм вычисления, там где ты его использовал.

undefined - это ключ, который ассациирован с каким то значением в Global Object.

То есть когда ты пишешь null в JS программе, то, формально выполняется неокторый код внутри Agent-а, который возвращает результат.

Когда ты используешь undefined - Agent - производит поиск идентификатора ровно так же как происходит поиск любого другого идентификатора, который определили лично ты при помощи var/let/const.

Этот поиск доходит до Global Enviroment и делает последнюю попытку поиска в Global Object где и есть property связанное с ключем undefined
