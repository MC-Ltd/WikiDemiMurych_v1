Описание всех алгоритмов которые связаны с этим термином, касаются терминов спецификации таких как:
global envidormen / module enviroment
variable enviroment
declaration enviroment

То есть использования жаргона Lexical Enviroment никак не может описать текущее поведение спецификации - однозначным образом.
