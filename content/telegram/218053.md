Выход из кода JS функции может быть осуществлен только двумя способами: 
return и throw.

return может быть опущен и тогда функция завершиться либо undefined либо возвращением связанного с this обьекта, если это была normal function являющаяся конструктором и вызванная при помощи оператора new.

Иными словами, если не знать изначальной задачи, и думать только о return или throw - то иных вариантов нет для normal function.

Есть еще async function и есть генераторы где процесс возвращения результата уже не обязательно зависит от return.
