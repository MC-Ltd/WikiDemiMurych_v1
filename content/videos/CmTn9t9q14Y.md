А возможно ли в JS перехватывать вызов всех функций?
Пример: при вызове любой функции выводить сообщение в консоль :

/*
    hack code
    ...
*/

function func() {
    return 1;
};

func(); // при вызове должно выводить в консоль сообщение 'FUNCTION CALL'

это можно сделать для какой-то отдельной функции с помощью Proxy :
function func2() {
    return 2;
};
func2 = new Proxy(
    func2,
    {
        apply( ...params ) { console.log("FUNCTION CALL"); Reflect.apply( ...params ) }
    }
);

а есть ли способ это сделать для ВСЕХ определённых в коде функций?
