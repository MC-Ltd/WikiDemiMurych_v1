> В современном JS есть два assignment patterns: object assignment pattern и array assignment pattern. 
> 
> Оба паттерна, работают абсолютно одинаково что для Regular Object, что для Exotic Object Array. То есть поведение каждого (OAP и  AAP) не изменяется к чему конкретно он применяется. 
> 
> Разница только в том, как сами по себе эти паттерны работают.
> 
> Object Assignment Patter - работает эффективнее всего, потому что он требует явным образом обозначенных ключей:
> var user = {login: "murych", pass: "123" };
> var {login, pass} = user;
> 
> var arr = ["murych", "123"];
> var {0: login, 1:pass} = arr;
> 
> Разницы не будет никакой. 
> 
> Однако в случае:
> var arr = ["murych", "123"];
> var [login, pass] = arr;
> 
> Вы теряете сразу минимум 10% производительности. Потому, что на уровне спецификации, паттерн выше требует создание полноценного процесса итерирования по всему arr. А не простого доступо по ключу.
