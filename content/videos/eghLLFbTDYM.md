> Не по темi.
> 
> Якщо ви створюєте функцію з іменем createCounter, ви повинні повернути об’єкт (той самий counter), який має можливість рахувати, щось визначати, тощо. Саме це є призначенням вашої функції, чи не так? Наприклад:
> const createCounter = () => {
>      let count = 0;
>      return {
>          increment: () => ++count
>      }
> }
> const counter1 = createCounter();
> const counter2 = createCounter();
> counter1.increment(); //1
> counter2.increment(); //1
> 
> Функції іменують дієсловами. Ваш приклад, де зовнішня функція повертає внутрішню, можна переписати так:
> const createIncrement = () => {
>      let count = 0;
>      return () => ++count;
> }
> const increment1 = createIncrement();
> const increment2 = createIncrement();
> increment1(); // 1
> increment2(); // 1
> 
> Я розумію, що задля простоти ви не дуже замислювались над своїм кодом, тому вважайте цей коментар моїми думками вголос, а не критикою.
