Таблетка для памяти, чтоб не рыться в Евангелии от ECMAScript: 

Let and const declarations define variables that are scoped to the running execution context's LexicalEnvironment. The variables are created when their containing Environment Record is instantiated but may not be accessed in any way until the variable's LexicalBinding is evaluated. A variable defined by a LexicalBinding with an Initializer is assigned the value of its Initializer's AssignmentExpression when the LexicalBinding is evaluated, not when the variable is created. If a LexicalBinding in a let declaration does not have an Initializer the variable is assigned the value undefined when the LexicalBinding is evaluated.

Var variables are created when their containing Environment Record is instantiated and are initialized to undefined when created.

Если почитать спецификацию, то можно сделать вывод о том, что EvaluateBody - это часть фазы Runtime Semantics. В спецификации есть раздел Runtime Semantics: EvaluateBody. EvaluateBody - не отдельная фаза, и она уж точно не идёт раньше Runtime Semantics. EvaluateBody используется во время выполнения программы, то есть тогда, когда код исполняется в фазе Runtime Semantics. 
Сначала выполняется Static Semantics. Сразу за этой фазой выполняется Runtime Semantics, в которой запускается EvaluateBody - выполнение тела скрипта (глобального кода).
EvaluateBody - повторяющийся процесс. Он точно запускается в момент выполнения тела функции. Про выполнение модулей не знаю. Возможно, для модулей описываются другие правила исполнения.
