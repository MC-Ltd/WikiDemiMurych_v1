class Chameleon {
	constructor(newColor = { newColor: 'green' }) {
		this.newColor = newColor
	}
	
	// remove static
	colorChange(newColor) {
		this.newColor = newColor
		return this.newColor
	}
}

const freddie = new Chameleon({ newColor: 'purple'})

console.log(1, freddie.colorChange('orange'))

console.log(2, freddie.colorChange('red'))

1. **Статический метод**: Метод `colorChange` был объявлен как статический, поэтому его нельзя было вызывать у экземпляра
2. **Деструктуризация в конструкторе**: Некорректный синтаксис для параметров по умолчанию
