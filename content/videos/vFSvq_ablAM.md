Вставлю ещё свои 5 копеек по поводу 1:02:27 "Не имеет значения последовательность выполнения асинхронного кода".
В целом, именно к этому и должен стремиться каждый хороший программист. Однако, на практике, возникают такие ситуации, когда программист **должен четко понимать** в какой последовательности выполниться то или иное API.

Например: мы хотим сделать тест, который покрывает асинхронную операцию наступающую при получении события с сервера (из сокета).
Если это Unit-тест, то нам не нужно тестировать событие сервера, нужно протестировать только тот юнит, в котором это событие обрабатывается. А это значит, что событие от сервера мы можем замокать (сэмулировать).

При этом, мы сталкиваемся с ситуацией, что нам __сначала__ нужно завести промис в тесте, а потом бросить событие. Но ключевое слово `await` прекратит выполнение нашего синхронного кода и до посылки события исполнение не дойдёт.

```javascript
it('handle async event test', async function() {
    const result = await EventEmitter.once(myUnit, 'some-event-from-server');

    // Ошибка: Эта строчка никогда не выполниться
    myUnit.emit('some-event-from-server');
});
```

Однако, знания о том, в какой последовательности работает наше API в JS-Агенте и в какой последовательности будут вызваны наши асинхронные коллбеки, мы можем переписать данный код так, чтобы он также "красиво" был написан и работал правильно:

```javascript
it('handle async event test', async function() {
    // Выполниться после создания промиса функцией once
    queueMicrotask(() => myUnit.emit('some-event-from-server'));

    const result = await EventEmitter.once(myUnit, 'some-event-from-server');


    // Наш результат
    void result;
});
```

Это самый простой пример. На практике, ситуации бывают гораздо сложнее и запутаннее, и разработчик должен понимать, как с такими ситуациями разбираться.

class CustomPromise {
    #value
    #reason
    #isCatch = false

    constructor(resolve, reject) {
        if (typeof resolve === 'function') {
            this.#value = resolve()

        }

        if (typeof reject === 'function') {
            this.#isCatch = true
            this.#reason = reject()
        }
    }

    then(cb) {
        if (this.#isCatch) return this

        try {
            this.#value = cb(this.#value)
        } catch (e) {
            this.#isCatch = true
            this.#reason = e.message
        }

        return this
    }

    catch(cb) {
        cb(this.#reason)
        this.#isCatch = false
        this.#value = void(0)

        return this
    }

    static resolve(value) {

        return new CustomPromise(() => value)
    }

    static reject(value) {

        return new CustomPromise(undefined, () => value)
    }
}
